# doorlist

A phone-sized copy of the door list flow: a home of upcoming events, event pages, invites with a moving gleam, a guest list, and a ticket code that changes every second.

Photos and text stay in this phone's browser. Tap **Edit**, then tap any photo or underlined label. Use **+** to add an event. Reset the demo from the profile menu.

## Add it to your iPhone

1. Open the site in Safari: the GitHub Pages link for this repo.
2. Tap the Share button.
3. Tap **Add to Home Screen**.
4. Open **doorlist** from the home screen.

The ticket code only keeps refreshing while that ticket screen is open.
